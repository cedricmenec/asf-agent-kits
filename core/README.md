# Offline research modules

This directory contains policy, GitHub-observation, checkpoint and local-fixture modules developed during earlier catalogue work. These modules are not the published agent executor by themselves.

The current workflow runs from `kits/opencode-openspec/templates/`. Start with [contributor guidance](../docs/contributing.md) for source locations and validation, or the [kit architecture](../docs/kits/opencode-openspec/architecture.md) for the runtime.

Historical design and qualification reports remain available in [Git history](https://github.com/cedricmenec/asf-agent-kits/tree/3ed348621cff28dc0b6be1503fce2a17bbc0f1e3/docs). Their simulations do not prove a live runtime, release identity or payment authorization.
