# About ASF Agent Kits

ASF Agent Kits is a catalogue of coding-agent workflows that you can install in a GitHub repository.

## What is a kit?

Think of a kit as a versioned recipe installed in your repository. It gives the agent a workflow to follow.

A kit packages one workflow, its helper files, configuration and documentation. Each kit has its own purpose, version, setup and limits.

## What the catalogue provides

The catalogue keeps reusable workflows in one place. It helps you choose a kit, install a pinned version and keep track of the installed files. The current install tooling supports the published OpenCode + OpenSpec kit.

## What you own

Your repository keeps its application, project instructions, task backlog, tests, CI, access settings and merge decisions. Read the selected kit's guide for its actual requirements.

## Different workflows, different needs

A workflow may use a written specification or a direct task. Future kits may coordinate several tasks or task waves. Availability is shown in the catalogue; a listed design profile is not necessarily a released kit.
