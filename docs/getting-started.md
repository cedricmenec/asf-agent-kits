# Getting started

Choose a workflow first. Then follow that kit's own installation and first-task guides.

## 1. Choose a kit

Check its purpose and release status in the documentation index. Use a published kit when you need an installable workflow. A planned profile is a description of intended work.

## 2. Read its overview

Confirm that the kit fits your project, stack, review process and access model. Read the limits before setting up execution.

## 3. Follow the kit's install guide

Use its published version and exact source commit. Review the file preview, conflicts and configuration. Each kit documents the steps it supports; there is no universal one-line installation across all kits.

## 4. Run one small task

Complete the kit-specific GitHub setup and start with a small, clear task. Review its outputs, checks and any provider costs before widening use.

## 5. Maintain the installed kit

Use the kit's update and troubleshooting guides. Keep project-owned files safe and review changes through your normal PR process.
