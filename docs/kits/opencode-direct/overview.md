# Overview and availability

OpenCode Direct is a planned optional profile. It is not an executable or published kit in this repository.

The catalogue contains its descriptor and a short design note. It has no release and the installation CLI accepts only opencode-openspec.

## Intended use

This profile is intended for direct OpenCode work without the full OpenSpec cycle. Its exact runtime, install procedure and guarantees are not yet delivered here.

Use the published OpenCode + OpenSpec kit today when you need an installable workflow. Do not use the Direct descriptor as an installation artifact.

## Relationship to future kits

ASF Agent Kits can host independently versioned workflows. Future work may include direct execution and workflows that coordinate several tasks or task waves. Availability, interfaces and guarantees must be documented when those kits are released.
